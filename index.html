Support Center & FAQ

Panduan cepat penggunaan konverter dan manajemen dokumen VexelFlow.

Bagaimana cara mengonversi banyak file sekaligus?

Seret beberapa file sekaligus ke area dashed dropzone di halaman Home, atau gunakan tombol Tambah Data untuk membuat antrean konversi baru, lalu klik Download All.

Apa fungsi fitur AI Converter di panel kanan?

AI Converter mengubah gambar bitmap (JPG/PNG) menjadi vektor SVG presisi tinggi dan mengekstrak layer terpisah dari dokumen PDF.

Apakah perubahan data tersimpan jika halaman dimuat ulang?

Ya. Seluruh operasi Create, Update, dan Delete otomatis tersinkronisasi dengan localStorage browser Anda.
